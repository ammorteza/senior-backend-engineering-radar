# Senior Backend Engineering Radar

A public learning radar for backend engineers growing from Senior toward Staff-level engineering.

## How to use it

Pick one blip and spend about 20 minutes: define the problem, understand how it works, examine trade-offs, and apply it to a production scenario.

## Rings

- **Adopt** — production-level competency is expected or strongly recommended.
- **Trial** — gain hands-on experience.
- **Assess** — understand architecture, use cases, failure modes, and trade-offs.
- **Caution** — avoid making this a default choice without a concrete reason.

This is a learning map, not a certification checklist. Context always matters.

Generated with the open-source AOE Technology Radar.
